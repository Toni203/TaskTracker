# TaskTracker

Небольшая программа для хранения задач.

## Требования
- .NET 6
- Windows 10

## Запуск
1. Откройте папку `TaskTracker`.
2. Выполните `dotnet run`.

## Структура
Исходный код находится в корне проекта.
