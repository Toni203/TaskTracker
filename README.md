# \# TaskTracker

# 

# \## Описание

# 

# TaskTracker — консольное приложение для хранения и управления задачами.

# Позволяет добавлять задачи и просматривать их список с отметкой о выполнении.

# Разработано на языке C# с использованием платформы .NET 8.

# 

# \## Используемые технологии

# 

# \- C#

# \- .NET 8

# \- Git

#
